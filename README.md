# WORDLY

Daily five-letter word guessing game.

## Accepted guess dictionary

The game bundles a local five-letter guess list in `words.txt` so guesses can be checked without a third-party API. The list is sourced from [tabatkins/wordle-list](https://github.com/tabatkins/wordle-list), which is distributed under the MIT License. It is used as the accepted-guess vocabulary; the daily answer pool remains separately curated in `index.html`.
